# Tristan Munnik | Portfolio

A dark, responsive portfolio built with React and Vite. It presents my background, projects, and contact details across separate routes, with animated page transitions and a persistent bottom section switcher.

## Requirements

- Node.js and npm

## Getting Started

```bash
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |

## Routes

| Route | Page |
| --- | --- |
| `/` | Home and introduction |
| `/work` | Selected projects |
| `/about` | About me |
| `/contact` | Contact information |

## Project Structure

```text
src/
	assets/       Local image assets
	components/   Route page components
	App.jsx       Routes, page transitions, and bottom navigation
	App.css       Portfolio layout and page styles
	index.css     Global styles
	main.jsx      React application entry point
```
